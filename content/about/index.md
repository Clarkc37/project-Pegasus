## About Global Guide Racing

Global Guide Racing provides data-driven predictions for jumps horse racing across the UK and Ireland. Every racecard is powered by the **Pegasus model** — a machine learning system trained on historical form, sectional times, going preferences, and trainer/jockey trends.

### How the Model Works

The Pegasus model analyses each horse's recent form, taking into account:

- **RPR (Racing Post Rating)** — the official speed figure
- **TS (Topspeed)** — a raw time-based rating
- **VDW (Van Der Whele)** — a composite class/distance/going score
- **Going preference** — how each horse performs on different ground conditions
- **Trainer form** — recent strike rate and course specialisation
- **Jockey bookings** — jockey/trainer combinations and recent form

Each horse receives a prediction score; lower scores indicate higher win probability. The horse with the lowest score is our **Top Tip**.

### Limitations

- Horse racing is inherently unpredictable. Our model is a guide, not a guarantee.
- Prices quoted are from the Racing Post API at the time of data collection and may change.
- Always check declarations, non-runners, and late changes before placing a bet.
